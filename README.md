# E-Commerce Sales Analytics

## Project Overview

This project analyzes e-commerce sales data using Python, SQL, and Power BI to understand sales performance, profitability, customers, products, and business trends.

## Tools & Technologies

- Python
- Pandas
- SQL
- MySQL
- Power BI
- Excel/CSV

## Project Objectives

- Analyze overall sales and profit
- Identify top-performing products and customers
- Analyze sales by category, sub-category, region, and state
- Understand yearly and monthly sales trends
- Analyze profit performance
- Study the relationship between discount and profit
- Create an interactive Power BI dashboard

## Python Analysis

Python and Pandas were used for:

- Data loading and exploration
- Data cleaning
- Handling missing values
- Sales and profit calculations
- Customer and order analysis
- Creating summary metrics

## SQL Analysis

MySQL was used to perform:

- Total sales and profit analysis
- Customer analysis
- Product analysis
- Category and sub-category analysis
- Top customer and product analysis
- Sales and profit aggregation
- Business performance analysis

## Power BI Dashboard

The Power BI dashboard contains two pages:

### 1. Executive Dashboard

Includes:

- Total Sales
- Total Profit
- Total Customers
- Total Orders
- Profit Margin
- Average Order Value
- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Sales Trend by Year
- Sales by Segment
- Sales by Ship Mode

### 2. Detailed Analysis

Includes:

- Top 10 Customers by Sales
- Top 10 Products by Sales
- Top 10 Products by Profit
- Sales by Sub-Category
- Profit by Sub-Category
- Sales by State
- Profit by State
- Quantity Sold by Category
- Discount vs Profit
- Monthly Sales Trend
- Sales vs Profit by Year

## Dashboard Features

- Interactive Year filter
- Region filter
- Category filter
- Page navigation
- Interactive charts
- KPI cards
- Sales and profit analysis

## Key Insights

- Identified top-performing customers and products.
- Compared sales and profit across categories and regions.
- Analyzed yearly and monthly sales trends.
- Identified profitable and less profitable product segments.
- Examined the impact of discounts on profitability.
